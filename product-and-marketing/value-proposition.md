# Value Proposition — VoidDrift
**Generated:** 2026-03-24

---

## Core Statement

**VoidDrift is the free browser game that lets you phase between three dimensions and compete globally — no install, no payment, just open and play.**

---

## Target Problem

Browser gamers want a high-quality, immediately playable experience that offers more than the usual simple 2D fare — but they don't want to install an app, create an account, or pay before they understand the game. They want: impressive visuals, a novel mechanic, and a reason to keep coming back (competitive drive).

---

## Key Benefits

| Benefit | Detail |
|---|---|
| **Instant play** | URL → playing in under 3 seconds; no account, no install |
| **Visually premium** | Three.js / React Three Fiber 3D — rare for browser games |
| **Novel mechanic** | Phase between crimson, cyan, and violet dimensions — each with unique obstacles |
| **Competitive replay** | Real-time global leaderboard via Supabase keeps players returning |
| **Free forever** | No energy systems, no pay walls, no battle pass |

---

## Value for Each Player Type

**Casual Player:** Opens link, experiences beautiful 3D game instantly, shares with friends
**Competitive Player:** Chases leaderboard position; daily play to improve rank
**Indie Game Fan:** Appreciates technical achievement (Three.js in browser) and design originality

---

## Proof Points

- Built with Three.js + React Three Fiber — technology typically reserved for 3D web applications, not casual games
- Supabase leaderboard: real-time persistent global scoring
- Three distinct dimension visual themes: crimson, cyan, violet — not a reskin, each has unique obstacle patterns
- Next.js deployment: fast load times, edge-optimized delivery via Vercel

---

## Competitive Advantage Summary

Most browser games are 2D ports of mobile games or minimal implementations. VoidDrift delivers a technically sophisticated 3D experience built natively for the web, with a mechanic (dimension phasing) that doesn't exist in the casual browser game space.
