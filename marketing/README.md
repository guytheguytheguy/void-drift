# Void Drift - Marketing Hub

> **"Phase through dimensions. Drift through the void."**

Browser-based 3D arcade game built with Three.js, React Three Fiber, and Supabase. Players navigate through procedurally-generated void spaces, avoiding obstacles and competing for the global leaderboard.

**Live at:** [voiddrift.dev](https://voiddrift.dev)
